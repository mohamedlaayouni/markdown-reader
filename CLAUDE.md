## Skill routing

Use gstack workflows only for these task categories:

- Product design planning or design-system work: use `/design-consultation` or `/plan-design-review`.
- Visual polish or UI consistency fixes: use `/design-review`.
- Bugs and root-cause debugging: use `/investigate`.
- Web-app QA that includes systematic interaction testing: use `/qa` or `/qa-only`.

Do not use `/browse` as the default for general browsing, web research, or ordinary URL navigation. Use the environment's standard web or browser tools unless the user explicitly requests the gstack browse workflow or another selected gstack workflow requires it.
